# Расчётное ядро — первая итерация

## Что умеет

- Принимать индивидуальные компоненты начислений для каждого сотрудника.
- Принимать премиальные фонды с независимыми списками участников и получателей.
- Распределять фонд поровну, пропорционально сменам, часам или пользовательским весам.
- Сохранять точность до копейки и распределять остаток округления последнему получателю.
- Применять ручной/импортированный НДФЛ либо отключённый режим.
- Возвращать расшифровку начислений по каждому сотруднику и итоговые суммы.

## Ограничения

- Вычисление оклада по сменам/часам пока задаётся внешним компонентом начисления; движок не выводит неизвестную формулу из названия должности или листа Excel.
- Встроенного автоматического налогового расчёта пока нет. Для него требуется отдельный налоговый профиль и реализация соответствующих правил с периодом действия.
- Значение оклада с неуказанным типом gross/net не преобразуется и отмечается предупреждением. Такой расчёт нельзя считать готовым к утверждению.
- В текущем интерфейсе этот модуль пока не подключён.
- Это промежуточное ядро, требующее тестирования на реальных контрольных ведомостях.
