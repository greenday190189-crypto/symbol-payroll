# Результаты первичного анализа исходной книги

Исходная книга содержит девять листов. Все листы оставляем как источники требований, но числовые значения не считаем утверждёнными тарифами: пользователь подтвердил, что цифры примерные.

| Лист | Наблюдения и вопросы |
|---|---|
| Сигаево | Разные знаменатели при распределении премии (49 и 36), индивидуальная формула оклада, деление оклада на 30 независимо от календарных дней. Требуется объяснить смысл знаменателей и исключения. |
| Дачная | Фонд премии делится на 6, но премию получают 4; отдельное исключение по сотруднику; встречаются делители 198 и 176. |
| Дубровская | Ставка за смену меняется в пометках; часть оплаты по окладу/22, часть по сменной ставке; указаны две ведомости. |
| Калинина | Смешанные способы оплаты; вспомогательные формулы в колонке L дают ошибки #VALUE! в сохранённых результатах. |
| Путейская | Смешанные способы оплаты; ставка рассчитывается через делитель 31 с пометкой «учитываем дни». |
| Электрозаводская | В примере нулевое количество смен приводит к #DIV/0! при распределении премии. Нужна блокирующая проверка. |
| Азина | Формула премии ссылается на пустые ячейки, хотя продажи и план находятся в других колонках; не переносить эту формулу без проверки. |
| Элеконд | Две ведомости на одном листе, периоды январь 2023 — февраль 2023. Требуется подтвердить, используется ли сейчас разбивка месяца. |
| увольнение | Отдельная ведомость при увольнении; состав компонентов неполный. Компенсацию отпуска нельзя считать юридически корректной без утверждённой методики. |

## Общие выводы

1. Листы представляют разные модели, а не единый шаблон.
2. Требуется настраиваемый движок правил, а не набор жёстко прошитых формул.
3. Ставки, планы, проценты и суммы из книги нельзя считать актуальными параметрами без подтверждения.
4. Ночные данные не предоставлены; соответствующую функциональность можно предусмотреть архитектурно, но нельзя включать неподтверждённые начисления.
5. До реализации производственного расчёта необходимо получить контрольные примеры, подтверждённые бухгалтером.
