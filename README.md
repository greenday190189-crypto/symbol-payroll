# Символ — система расчёта заработной платы

Локальное Windows-приложение для подготовки, проверки и утверждения расчётных ведомостей сети магазинов «Символ».

> Текущий статус: реализован первый сквозной сценарий месячного расчёта — от ввода показателей до сохранения и утверждения ведомости. Это ещё не производственная версия и не замена бухгалтерской проверке. Перед реальным использованием обязательны контрольные сверки.

## Принципы

- Python + PySide6, SQLite, openpyxl; локальная работа на Windows 10/11.
- Индивидуальные схемы оплаты с наследованием и переопределением правил: организация → магазин → должность → сотрудник → период.
- Настраиваемые начисления, премии и удержания через безопасный движок выражений; произвольный Python из интерфейса запрещён.
- Неизменяемые снимки утверждённых расчётов и версионирование правил.
- НДФЛ: автоматический, ручной и импортированный режимы; автоматический расчёт включается только при наличии подтверждённых исходных данных и актуальной версии налоговых правил.
- Импорт/экспорт Excel с предварительным просмотром, сопоставлением колонок и проверками.



### Импорт Excel (первый этап)

Во вкладке «Расчёты» доступен импорт листа Excel в выбранный расчётный период:

1. Выберите файл .xlsx/.xlsm, лист и магазин, к которому относятся сотрудники.
2. Приложение предлагает сопоставление колонок по названиям заголовков; его можно изменить вручную.
3. Предпросмотр показывает строки, найденных сотрудников и ошибки до записи в базу.
4. Импорт разрешён только при отсутствии ошибок; неизвестные и неоднозначные сотрудники, дубли и отрицательные/некорректные числовые значения блокируют запись.
5. Колонки, которые не сопоставлены, сохраняют ранее введённые значения. Сотрудники, отсутствующие в выбранном листе, не изменяются.
6. Формулы без сохранённого вычисленного результата блокируются. Само приложение формулы из Excel не исполняет.

Импорт выполняется для одного листа и одного магазина за раз. Для нескольких магазинов повторите процедуру для каждого листа. Пока импортируются операционные показатели, а не карточки сотрудников, ставки окладов или сами правила оплаты.

## Текущие возможности и ограничения

- Справочники магазинов и сотрудников, индивидуальная база оклада gross/net/unconfirmed.
- Редактор версионируемых правил с приоритетами организации, магазина, должности, сотрудника и периода.
- Месячный расчёт: смены, часы, продажи, план, авансы, удержания, ручной НДФЛ и корректировки.
- Дополнительные числовые параметры можно передавать в формулы в виде JSON-объекта на строке сотрудника.
- Расшифровка начислений и удержаний, пересчёт черновика и утверждение периода.
- Изменение вводных данных сбрасывает предыдущие расчётные снимки; после утверждения SQLite блокирует изменение снимков и вводных.
- Оклад с неподтверждённой базой gross/net не включается в итоги; автоматический НДФЛ отключён до настройки налогового профиля.
- Распределение премиальных фондов реализовано в расчётном ядре, но пока не подключено к месячному интерфейсу.
- Импорт Excel с предварительным просмотром и проверками реализован для показателей периода.
- Экспорт Excel формирует сводку по сети, итоги по магазинам и персональные листки из сохранённых снимков; повторный расчёт при экспорте не выполняется.
- Утверждённые снимки содержат исторические сведения о магазине и должности сотрудника для будущих отчётов.
- Реализован отдельный сценарий увольнения: ввод фактических смен/часов, ручных окончательных начислений, авансов, удержаний и НДФЛ; расчёт и утверждение с блокировкой результата.
- В месяце увольнения полный месячный оклад автоматически не добавляется; для оплаты фактического времени требуется подтверждённое правило/формула. Компенсация неиспользованного отпуска автоматически не рассчитывается.
- Уволенный сотрудник сохраняется в исторических ведомостях периодов до даты увольнения и исключается из более поздних периодов.
- Экспорт окончательного расчёта увольнения в отдельную Excel-книгу из сохранённого результата; повторный расчёт при экспорте не выполняется.
- Резервное копирование: автоматическая ежедневная копия при запуске (хранение 30 последних), ручное создание копии, проверка целостности и внешних ключей, восстановление с предварительным созданием страховочной копии.
- Полноценные налоговые правила и Windows-инсталлятор ещё не реализованы.

Вкладка «Расчёты» работает со всеми активными сотрудниками. Отсутствующие вводные строки считаются нулевыми операционными показателями с предупреждением. Это поведение не заменяет проверку полноты ведомости.

## Запуск (разработка)

Требуется Python 3.11+.

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -e ".[dev]"
python -m symbol_payroll
```
